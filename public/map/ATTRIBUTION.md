# cebu-boundaries.geojson — sources & attribution

53 features: Cebu Province's 50 municipalities/component cities, plus the 3
independent Highly Urbanized Cities (Cebu City, Lapu-Lapu City, Mandaue City)
that PSGC-grouped provincial datasets exclude by definition.

Generated by `scripts/build-cebu-boundaries.mjs`. Re-run that script if the
upstream sources publish an update — do not hand-edit this file.

## Basemap

When `NEXT_PUBLIC_MAP_PROVIDER_TOKEN` is configured, the live Leaflet map
uses CARTO's **Dark Matter** raster tiles. Required runtime attribution is
shown directly on the map:

- [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)
- [CARTO](https://carto.com/attributions)

## Sources
